## Часть A. Поддержка RAII

Менеджер памяти из ДЗ №11 был доработан минимально: в `Pointer` добавлена поддержка disposal-протокола.

```ts
[Symbol.dispose](): void {
  this.free();
}
```

Теперь heap-указатель из `mem.alloc(...)` можно использовать через `using`:

```ts
using pointer = mem.alloc(128);

pointer.change(arrayBuffer);
```

При выходе из области видимости JavaScript автоматически вызывает `pointer[Symbol.dispose]()`, а тот внутри вызывает уже существующий `free()`.

Так ручное освобождение:

```ts
const pointer = mem.alloc(128);
pointer.change(arrayBuffer);
pointer.free();
```

заменяется автоматическим:

```ts
using pointer = mem.alloc(128);
pointer.change(arrayBuffer);
```

Внутренняя модель памяти не меняется:

- `free()` по-прежнему освобождает только heap-блоки;
- повторное освобождение запрещено;
- после освобождения указатель становится недействительным;
- блок возвращается в список свободных блоков кучи.

Итого: `Symbol.dispose` просто связывает `using` с уже реализованной логикой `free()`, что и даёт RAII-поведение.

## Часть B. Счётчик ссылок `Rc`

`Rc` — это обёртка над heap-указателем `Pointer` со счётчиком владельцев.

- `new Rc(pointer)` создаёт первого владельца и ставит `count = 1`;
- `clone()` создаёт нового владельца того же heap-блока и увеличивает `count`;
- `[Symbol.dispose]()` уменьшает `count`;
- когда `count` становится равен `0`, вызывается `pointer.free()`.

Общее состояние хранится в одном объекте:

```ts
interface RcState {
  pointer: Pointer;
  count: number;
}
```

Все клоны `Rc` делят один и тот же `RcState`, поэтому новая область памяти при `clone()` не создаётся: появляется только ещё один владелец того же heap-блока.

У каждого экземпляра `Rc` есть собственный флаг `disposed`, а `count` общий. Это позволяет:

- запретить повторный dispose одного и того же владельца;
- запретить `clone()`, `deref()` и `change()` после dispose;
- освобождать память только после уничтожения последнего владельца.

Пример:

```ts
const mem = new Memory(100 * 1024, { stack: 10 * 1024 });

using pointer1 = new Rc(mem.alloc(128));
pointer1.change(arrayBuffer);

using pointer2 = pointer1.clone();
```

Здесь `pointer1` и `pointer2` владеют одним heap-блоком. Память освободится автоматически только после выхода из области видимости обоих владельцев.
