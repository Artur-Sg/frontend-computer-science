# indexOf и lastIndexOf через бинарный поиск

Реализованы функции `indexOf` и `lastIndexOf` для отсортированного массива.

`indexOf` возвращает первое вхождение значения, `lastIndexOf` — последнее. Если значение не найдено, возвращается `-1`.

Функции работают с массивами чисел и строк, а также с массивами объектов через `selector`.

### Идея решения

Бинарный поиск каждый раз берёт середину текущего диапазона и отбрасывает половину массива.

Обычный бинарный поиск останавливается при первом совпадении, но здесь этого недостаточно: в массиве могут быть
повторяющиеся значения.

Поэтому:

- `indexOf` при совпадении запоминает индекс и продолжает искать левее;
- `lastIndexOf` при совпадении запоминает индекс и продолжает искать правее.

### Selector

Для массивов объектов можно передать функцию `selector`, которая возвращает значение для сравнения:

```ts
indexOf(users, 42, (item) => item.age);
lastIndexOf(users, 42, (item) => item.age);
```

Без `selector` элемент массива используется как значение напрямую.

### Важно

Массив должен быть заранее отсортирован по тому же значению, по которому выполняется поиск.

Если массив не отсортирован, бинарный поиск может вернуть неверный результат.

### Сложность

- время: `O(log n)`;
- память: `O(1)`.
