# Лекция 22

## Продвинутые регулярные выражения: lookahead и lookbehind

### Движение по строке

Движок регулярных выражений читает строку слева направо. Если часть шаблона совпала, а дальше совпадение сорвалось,
движок может вернуться назад и попробовать другой вариант. Такой механизм называется `backtracking`.

Например:

```js
/a+b/
```

В строке `aaaaac` движок сначала съест все `a`, затем попробует найти `b`, не найдёт его и начнёт откатываться назад.

### Опережающие проверки

Lookahead проверяет, что дальше по строке есть или нет нужный шаблон, но не включает этот фрагмент в результат.

Виды lookahead:

- `(?=...)` — позитивная опережающая проверка;
- `(?!...)` — негативная опережающая проверка.

Пример:

```js
const regex = /cat(?= dog)/;

regex.test('cat dog');  // true
regex.test('cat fish'); // false
```

Здесь `cat` находится только если после него идёт ` dog`, но само ` dog` не входит в совпадение.

### Ретроспективные проверки

Lookbehind проверяет, что перед текущей позицией есть или нет нужный шаблон.

Виды lookbehind:

- `(?<=...)` — позитивная ретроспективная проверка;
- `(?<!...)` — негативная ретроспективная проверка.

Пример:

```js
const regex = /(?<=dog )cat/;

regex.test('dog cat');  // true
regex.test('bird cat'); // false
```

Здесь `cat` находится только если перед ним стоит `dog `.

### Проверка условий без захвата текста

Lookahead часто используют для валидации строк, когда нужно проверить несколько независимых условий.

Например, строка должна содержать хотя бы одну цифру и хотя бы одну заглавную букву:

```js
/^(?=.*\d)(?=.*[A-Z]).+$/
```

Каждая проверка стартует от начала строки:

- `(?=.*\d)` проверяет, что где-то дальше есть цифра;
- `(?=.*[A-Z])` проверяет, что где-то дальше есть заглавная буква;
- `.+` уже описывает сами символы строки.

### Зачем это нужно в домашнем задании

В задании lookahead и lookbehind полезны в двух местах:

- при поиске чисел нужно проверить, что число не является частью слова или версии;
- при проверке пароля нужно убедиться, что строка содержит несколько обязательных типов символов.

То есть акцент этой лекции — не только найти сам фрагмент, но и проверить контекст вокруг него или глобальные условия
для всей строки.
