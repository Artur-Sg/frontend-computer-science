В задании нужно реализовать два регулярных выражения:

- `numberRegex` — поиск чисел в тексте;
- `passwordRegex` — проверка сложности пароля.

### Поиск чисел

Регулярное выражение должно находить:

- целые числа: `42`, `-5`, `0`;
- дробные числа: `3.14`, `-0.5`, `.5`.

При этом важно не забирать числа из другого токена:

- `version2` не должен давать `2`;
- `1.0.2` не должен разбиваться на `1.0` и `.2`.

Реализация:

```ts
export const numberRegex = /(?<![\w.])-?(\d+\.\d+|\d+|\.\d+)(?!\.\d|\w)/g;
```

Основная часть числа:

```regex
-?(\d+\.\d+|\d+|\.\d+)
```

Она поддерживает:

- необязательный минус `-?`;
- дробные числа с цифрами до и после точки: `100.5`, `-0.5`;
- целые числа: `42`, `-5`, `0`;
- дробные числа без целой части: `.5`.

Контекст вокруг числа проверяется отдельно:

- `(?<![\w.])` — перед числом не должно быть буквы, цифры, `_` или точки;
- `(?!\.\d|\w)` — после числа не должно быть продолжения версии вида `.1` или символа слова.

За счёт этого `version2` не даёт совпадение `2`, а `2.0.1` не разбивается на `2.0` и `.1`. При этом число перед
пунктуацией, например `42.`, находится как `42`.

### Проверка пароля

Пароль нужно проверить целиком, поэтому выражение должно быть привязано к началу и концу строки через `^` и `$`.

Для требований вида "строка содержит хотя бы один символ такого типа" удобно использовать позитивные lookahead-проверки:

```regex
(?=.*[A-Z])
```

Такая проверка смотрит вперёд от начала строки и убеждается, что дальше есть хотя бы одна заглавная буква. При этом
сама проверка не забирает символы из строки, поэтому несколько условий можно поставить подряд.

Для пароля нужны проверки:

- есть заглавная буква;
- есть строчная буква;
- есть цифра;
- есть спецсимвол;
- общая длина от `8` до `20` символов.

Реализация:

```ts
export const passwordRegex = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[!@#$%^&*])[A-Za-z0-9!@#$%^&*]{8,20}$/;
```

Выражение состоит из двух частей.

Первая часть проверяет обязательные условия:

```regex
^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[!@#$%^&*])
```

- `(?=.*[A-Z])` — где-то в строке есть заглавная буква;
- `(?=.*[a-z])` — где-то в строке есть строчная буква;
- `(?=.*\d)` — где-то в строке есть цифра;
- `(?=.*[!@#$%^&*])` — где-то в строке есть спецсимвол.

Вторая часть описывает всю строку:

```regex
[A-Za-z0-9!@#$%^&*]{8,20}$
```

Она ограничивает набор допустимых символов и длину пароля.
