# Лекция 21

## Продвинутые регулярные выражения

### Группы

Круглые скобки `()` в регулярных выражениях нужны не только для группировки, но и для захвата совпавшего фрагмента.

Группы позволяют:

- локально ограничивать действие альтернации `|`;
- применять квантификатор ко всей последовательности;
- переиспользовать найденные фрагменты в замене;
- ссылаться на уже найденный текст через обратные ссылки.

Пример группировки:

```js
/(cat|dog) (barks|jumps)/
```

Здесь:

- первая группа выбирает `cat` или `dog`;
- вторая группа выбирает `barks` или `jumps`.

### Нумерация групп

Группы нумеруются слева направо по открывающей скобке.

```js
/((cat|dog) (barks|jumps))/
```

В этом выражении:

- группа 1 — всё выражение целиком внутри внешних скобок;
- группа 2 — `(cat|dog)`;
- группа 3 — `(barks|jumps)`.

### Квантификаторы и группы

Квантификатор можно применять ко всей группе:

```js
/(ab)+/
```

Такое выражение ищет одну или более последовательностей `ab`.

### Захватывающие и незахватывающие группы

По умолчанию группа захватывает совпавший текст:

```js
const match = 'cat jumps'.match(/(cat|dog) (jumps|runs)/);
console.log(match[1]); // cat
console.log(match[2]); // jumps
```

Если группа нужна только для структуры выражения, можно использовать незахватывающую форму:

```js
/(?:cat|dog)/
```

Она группирует альтернативу, но не добавляет новую сохранённую группу в результат.

### Именованные группы

В JavaScript можно задавать группам имена:

```js
/(?<user>\w+)@(?<domain>\w+\.\w+)/
```

После совпадения к ним можно обратиться по имени:

```js
const match = 'bob@example.com'.match(/(?<user>\w+)@(?<domain>\w+\.\w+)/);
console.log(match?.groups?.user);   // bob
console.log(match?.groups?.domain); // example.com
```

### Замены через группы

Группы часто используются в `replace`.

Через `$1`, `$2` и так далее можно ссылаться на захваченные части:

```js
'John Doe'.replace(/(\w+) (\w+)/, '$2, $1');
// Doe, John
```

Это полезно для:

- перестановки частей строки;
- простого шаблонизатора;
- нормализации данных.

### Именованные группы в replace

Если замена делается функцией, в неё можно получить объект `groups`:

```js
const result = 'John Doe'.replace(
  /(?<first>\w+) (?<last>\w+)/,
  (match, first, last, offset, source, groups) => `${groups.last}, ${groups.first}`,
);
```

### Обратные ссылки

Обратная ссылка позволяет сослаться на уже захваченный текст внутри того же регулярного выражения.

Пример:

```js
/(['"])(.*?)\1/
```

Здесь:

- первая группа запоминает тип кавычки;
- `\1` требует, чтобы закрывающая кавычка совпала с открывающей.

То есть выражение найдёт:

- `"text"`
- `'text'`

но не примет строку с разными кавычками по краям.

### Где это полезно в задачах лекции

В домашнем задании этой лекции продвинутые regex-приёмы нужны для трёх типичных сценариев:

1. найти повторяющиеся подряд символы и схлопнуть их;
2. заменить шаблонные плейсхолдеры по имени;
3. найти арифметическое выражение внутри текста и заменить его на вычисленное значение.

То есть акцент уже не только на “найти совпадение”, а на:

- захват частей строки;
- повторное использование групп;
- замену через `replace`;
- работу с несколькими совпадениями внутри одного текста.
