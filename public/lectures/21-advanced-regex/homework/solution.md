# Решение

Реализованы три функции:

- `zipStr` — схлопывает подряд идущие повторяющиеся фрагменты;
- `format` — подставляет значения из объекта в строковый шаблон;
- `calc` — находит арифметические выражения в тексте и заменяет их результатом вычисления.

### Сжатие строки

Для поиска повторов используется выражение:

```regex
(\w+)\1+
```

Группа `(\w+)` запоминает последовательность символов, а обратная ссылка `\1+` ищет одно или несколько повторений
этой же последовательности сразу после неё. Вся найденная конструкция заменяется содержимым первой группы — `$1`.

Одной замены недостаточно: после схлопывания фрагмента в строке могут появиться новые соседние повторы. Поэтому
`replace` вызывается в цикле, пока результат не перестанет изменяться.

Например, строка `abbaabbafffbezza` преобразуется в несколько этапов:

```txt
abbaabbafffbezza -> abbafbezza -> abafbeza
```

Таким образом, функция умеет схлопывать не только одинаковые символы вроде `fff`, но и повторяющиеся фрагменты вроде
`abbaabba`.

### Простой шаблонизатор

Плейсхолдеры находятся выражением:

```regex
\$\{(\w+)\}
```

Символы `$`, `{` и `}` экранируются, потому что имеют специальное значение в регулярных выражениях. Группа `(\w+)`
сохраняет имя параметра внутри плейсхолдера.

В callback метода `replace` первым аргументом приходит вся найденная строка, а вторым — содержимое первой группы.
Полученное имя используется как ключ объекта `params`:

```ts
params[match]
```

Значение приводится к строке через `String`, поэтому поддерживаются и строки, и числа. Если ключ отсутствует, исходный
плейсхолдер остаётся в шаблоне без изменений.

### Вычисление выражений в строке

Арифметические фрагменты находятся выражением:

```regex
\(?\d+(?:\s*(?:\*\*|[+\-*])\s*\d+\)?)+
```

Оно состоит из следующих частей:

- `\(?` — необязательная открывающая скобка;
- `\d+` — первое целое число;
- `(?:\*\*|[+\-*])` — один из операторов `**`, `+`, `-` или `*`;
- `\s*` — необязательные пробелы вокруг оператора;
- завершающая группа с оператором и числом повторяется один или несколько раз.

Благодаря этому находятся как простые выражения `2 * 10`, так и цепочки или выражения со скобками, например
`(10 + 15 - 24) ** 2`.

Метод `replace` передаёт найденное выражение в callback. Для вычисления используется конструктор `Function`, а
полученный результат преобразуется в строку и подставляется обратно в исходный текст.

### Ограничения

`calc` рассчитан на примеры из задания: целые неотрицательные числа, операторы `+`, `-`, `*`, `**` и простые скобки.
Он не является полноценным парсером, не проверяет баланс скобок и не поддерживает произвольную вложенность.

Конструктор `Function` выполняет переданную строку как JavaScript-код. Здесь вход предварительно ограничивается
регулярным выражением, но для обработки недоверенных данных в реальном приложении вместо него нужен отдельный
арифметический парсер.
