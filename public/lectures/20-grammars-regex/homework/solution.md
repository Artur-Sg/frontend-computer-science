# Решение

Реализованы три регулярных выражения:

- `emailRegex` для проверки email-адреса;
- `numberRegex` для поиска чисел в тексте;
- `dateRegex` для извлечения дат в двух форматах.

### Проверка email

`emailRegex` проверяет строку целиком через якоря `^` и `$`.

Внутри шаблон разбит на три части:

- до `@` допускаются латинские буквы, цифры, точки, подчёркивания и дефисы;
- после `@` проверяется домен;
- доменная зона ограничена длиной от `2` до `6` букв.

То есть выражение не ищет email как подстроку, а валидирует всю строку целиком.

### Поиск чисел в тексте

`numberRegex` поддерживает несколько форм записи числа:

- целые значения;
- отрицательные значения;
- числа с дробной частью;
- записи вида `.5`.

Для обычных целых и дробных значений используется граница слова `\b`, чтобы не захватывать лишние символы вокруг
числа. Отдельно добавлена ветка для формата `.5`, потому что у него нет целой части перед точкой.

В результате выражение находит:

- `42`
- `-5`
- `0`
- `3.14`
- `-0.5`
- `.5`

### Извлечение дат

`dateRegex` поддерживает две альтернативы:

- `DD.MM.YYYY`;
- `YYYY-MM-DD`.

В выражении отдельно ограничиваются:

- диапазон дня;
- диапазон месяца;
- допустимый диапазон годов.

Для дня используется шаблон `01–31`, для месяца — `01–12`, а для года — диапазон `1900–2099`.

### Замечание

Регулярные выражения в этой задаче проверяют формат строки, но не полноценную календарную корректность. Например,
дата вроде `31.02.2025` может формально подходить под шаблон дня, месяца и года, хотя такой даты в календаре нет.
