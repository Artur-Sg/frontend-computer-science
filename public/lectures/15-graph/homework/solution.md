Реализованы две части:

- `Matrix<T>` — матрица смежности поверх `ArrayBuffer`;
- `Graph<T>` — граф на основе этой матрицы.

`Matrix` поддерживает два режима создания:

```ts
new Matrix(Uint8Array, 10, 10);
new Matrix(10, 10, customElementView);
```

Для typed array-конструктора матрица автоматически создаёт числовой `ElementView`:

- `0` / `0n` означает отсутствие связи;
- `1` / `1n` означает единичную связь;
- чтение и запись значения выполняются автоматически по типу массива.

Для кастомного веса можно передать собственный `ElementView<T>`, который задаёт:

- `read` и `write` для чтения и записи значения;
- `zero` и `one` для пустой и единичной связи;
- `isZero`, чтобы граф понимал, есть связь или нет.

Внутри матрица хранит один `ArrayBuffer`, а доступ к ячейке считается по формуле:

```ts
row * width + col
```

с учётом `bytesPerElement` из `ElementView`.

`Graph` использует эту матрицу смежности и поддерживает:

- ориентированный режим;
- неориентированный режим;
- числовые typed arrays;
- bigint typed arrays;
- кастомный `ElementView` для другого формата веса.

В конструкторе `Graph` проверяется, что матрица смежности квадратная (`N × N`).

Для неориентированного графа:

- `addEdge(a, b)` записывает вес в обе стороны;
- `removeEdge(a, b)` удаляет связь в обе стороны;
- `hasEdge(a, b)` возвращает `true` только если связь есть симметрично с обеих сторон.

Для ориентированного графа:

- `addArc(a, b)` работает только в одном направлении;
- `removeArc(a, b)` удаляет только указанную дугу;
- `hasArc(a, b)` проверяет строгое направление.

`traverse()` реализован через BFS:

- стартовый узел валидируется явно;
- уже посещённые вершины игнорируются;
- очередь реализована через массив и индекс `head`, без `shift()`;
- для стартовой вершины в callback передаётся `weight: undefined`
- для typed array-матрицы замыкание возвращается как `Graph<Uint8Array>`;
- для кастомного `ElementView` замыкание строится на той же схеме веса, но с использованием `one`;
- во всех случаях исходные веса рёбер в замыкании не сохраняются;


`transitiveClosure()` строит граф достижимости и не мутирует исходный граф.
Замыкание строится по алгоритму Уоршелла.
